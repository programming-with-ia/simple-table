# Simple Table for React - LLM Instruction Guide

This document provides a comprehensive understanding of the `@simple-table/react` package, built to help AI models like yourself write efficient, correct, and robust code using the `SimpleTable` component. It synthesizes the framework API, typing systems, features, and best practices available in the project.

## 1. Overview and Core Philosophy

`SimpleTable` is a lightweight, high-performance data grid and table component for modern React apps (React 18+, Next.js, Remix, Vite). The core logic is built in a vanilla framework-agnostic package (`simple-table-core`), and the React package (`@simple-table/react`) acts as a wrapper that maps standard core properties into React paradigms, enabling React components for renderers.

### Core Architecture
- **DOM Container Strategy:** The React `SimpleTable` component attaches a vanilla SimpleTable instance to a container `div` via a ref (`containerRef`).
- **Imperative API:** It exposes the `TableAPI` (from `simple-table-core`) back to the parent React component through React's `forwardRef`.
- **Framework Portals:** It uses a custom `ImperativeDomSlot` strategy alongside `wrapReactRenderer` to seamlessly convert React components (used as renderers for cells, headers, and footers) into raw DOM nodes that the vanilla table expects.
- **Component Re-rendering:** React's virtual DOM is bypassed for inner table updates. Data updates trigger vanilla methods (`api.updateData()`), and config changes rebuild or update the table instance, keeping performance blazingly fast.

## 2. Installation and Basic Setup

### Dependencies
```bash
npm install @simple-table/react
```

### Minimal Setup

Import `SimpleTable` and `asRows` from `@simple-table/react`. Standard CSS is imported from `simple-table-core/styles.css`.

```tsx
import React, { useRef, useState } from "react";
import { SimpleTable, ReactHeaderObject, TableAPI, asRows } from "@simple-table/react";
import "simple-table-core/styles.css";

// 1. Define your data model
type User = {
  id: string;
  name: string;
  age: number;
};

// 2. Define standard columns using ReactHeaderObject
const columns: ReactHeaderObject<User>[] = [
  { headerName: "ID", field: "id", width: 100 },
  { headerName: "Name", field: "name", width: 200, sortable: true },
  { headerName: "Age", field: "age", width: 100, align: "right" }
];

export default function MyTable() {
  const tableRef = useRef<TableAPI>(null);

  const [data] = useState<User[]>([
    { id: "1", name: "Alice", age: 28 },
    { id: "2", name: "Bob", age: 34 }
  ]);

  return (
    <div style={{ height: "400px", width: "100%" }}>
      <SimpleTable
        ref={tableRef}
        columns={columns}
        // asRows ensures the data satisfies the expected Row format internally
        data={asRows(data)}
        getRowId={(row) => row.id} // Essential for tracking and updates
        theme="light" // or "dark"
      />
    </div>
  );
}
```

## 3. The React Header Object & Custom Renderers

Unlike the vanilla `SimpleTableConfig`, the React package introduces specific types that allow passing native React components. These are strictly typed in `ReactHeaderObject<TRow>`.

### Customizing Cells with React Components

You can define a `cellRenderer` inside the column configuration that returns standard JSX.

```tsx
import { ReactHeaderObject, ReactCellRenderer } from "@simple-table/react";

const StatusRenderer: ReactCellRenderer<User> = ({ value, row }) => {
  const color = value === "active" ? "green" : "red";
  return <span style={{ color }}>{value}</span>;
};

const columns: ReactHeaderObject<User>[] = [
  // ...other columns
  {
    headerName: "Status",
    field: "status",
    cellRenderer: StatusRenderer
  }
];
```

### Customizing Headers and Footers

Similarly, headers and footers support native React renderers.

```tsx
const columns: ReactHeaderObject<User>[] = [
  {
    headerName: "Revenue",
    field: "revenue",
    headerRenderer: ({ column }) => <strong>{column.headerName} 💰</strong>,
    footerRenderer: ({ column }) => <span>Total: $1000</span>
  }
];
```

## 4. Understanding the Imperative TableAPI

Because `SimpleTable` optimizes updates by bypassing React state where possible, it provides a `TableAPI` object accessible via `useRef`. This allows programmatic control over the table.

```tsx
const tableRef = useRef<TableAPI>(null);

// Example uses:
const handleExport = () => tableRef.current?.exportToCSV("users.csv");
const selectAll = () => tableRef.current?.selectAllFilteredRows();
const getSelectedData = () => tableRef.current?.getSelectedRows();
```

### Commonly Used API Methods:
- `exportToCSV(filename?: string)`
- `getSelectedRows()`
- `selectAllFilteredRows()`
- `deselectAllRows()`
- `collapseAllGroups()` / `expandAllGroups()`

## 5. Advanced Features Configuration

`SimpleTable` supports advanced features out-of-the-box through its configuration props.

### 5.1 Pagination
Pagination can be enabled via `pagination` and `paginationPageSize`.

```tsx
<SimpleTable
  columns={columns}
  data={asRows(data)}
  getRowId={(row) => row.id}
  pagination={true}
  paginationPageSize={50}
/>
```

### 5.2 Row Selection
Enable checkboxes and manage selection.

```tsx
<SimpleTable
  columns={columns}
  data={asRows(data)}
  getRowId={(row) => row.id}
  rowSelection="multiple" // 'single' | 'multiple'
  onRowSelectionChange={(selectedIds) => console.log("Selected IDs:", selectedIds)}
/>
```

### 5.3 Quick Filter (Global Search)
Enable global table search.

```tsx
const [search, setSearch] = useState("");

<input value={search} onChange={(e) => setSearch(e.target.value)} />

<SimpleTable
  columns={columns}
  data={asRows(data)}
  getRowId={(row) => row.id}
  quickFilterText={search} // Automatically filters rows matching the text
/>
```

### 5.4 Themeing
Simple Table supports simple light/dark modes or full custom theming.

```tsx
<SimpleTable
  // ...
  theme="dark" // Default light theme can be overwritten
  // Or provide an object
  customTheme={{
    fontFamily: "Inter, sans-serif",
    headerBackgroundColor: "#1e1e1e",
    rowBackgroundColor: "#121212",
    textColor: "#ffffff"
  }}
/>
```

### 5.5 Animations and UI Feedback
Enable built-in cell flashing for real-time data updates.

```tsx
<SimpleTable
  // ...
  enableCellAnimations={true} // Flashes green for increase, red for decrease on update
/>
```

## 6. Performance Considerations
- **Use `asRows(data)`:** Always pass your data through `asRows()` when supplying the `data` prop.
- **Reference Equality:** Maintain reference equality for `columns` (use `useMemo` or declare them outside the component). Passing a new array of columns on every render forces the table to unnecessarily rebuild.
- **Data Updates:** To update data, update the React state passed to `data` as usual. The `SimpleTable` component detects data reference changes and effectively calls the internal Vanilla instance without remounting DOM elements.

## 7. Typing Guidelines for LLMs
- Always use `ReactHeaderObject<YourModel>` for column definitions. Do not use `ColumnType` or `SimpleTableConfig` from `simple-table-core` directly when constructing React views.
- Make sure to import types correctly:
  - `TableAPI`, `asRows` from `@simple-table/react`
  - Renderers: `ReactCellRenderer`, `ReactHeaderRenderer`, `ReactFooterRenderer` from `@simple-table/react`

By following these principles, you will seamlessly generate production-grade table components utilizing Simple Table in React.
